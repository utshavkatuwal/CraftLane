# CraftLane

A modern platform for discovering and showcasing creative work.

CraftLane is a work in progress, built with a focus on clean design, usability, and maintainable code.

### Tech Stack
- React
- TypeScript
- Vite
- CSS

### Getting Started

```bash
cd frontend
npm install
npm run dev
```
